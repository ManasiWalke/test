⚖️ AI Ethics & Responsible Use

🤝 Helpful (HAM)

Responses are designed to be genuinely helpful, using warm and encouraging language tailored to each user's context.

🎯 Accurate

Advice is evidence-based, drawing on established nutritional science and adapted to the user's specific health conditions.

🧩 Mindful

Cultural sensitivity and local food availability are always considered. Advice respects individual diversity.

🛡️ Guardrails

Harmful content is automatically detected and blocked. Dangerous diet advice, self-harm, and unsafe recommendations are never generated.

🔒 Privacy

No user data is stored. Information provided is used only for generating personalized responses in the current session.

📋 Transparency

Users are always reminded that AI advice is not a substitute for professional medical consultation.

🏗️ Application Architecture

Frontend: Vanilla HTML5 / CSS3 / JavaScript — single-page application with tab navigation

Backend: Python Flask REST API — two agent endpoints (/api/generate-plan, /api/query)

AI Engine: IBM Granite 13B Instruct v2 via ibm-watsonx-ai SDK

Agentic Pattern: Prompt engineering with role injection, context injection, structured output formatting

Safety Layer: Input + output guardrails with keyword filtering; HAM-aligned prompt templates
